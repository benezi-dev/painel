🍕 Painel Benezi

Cole um token do GitHub. Ele fica salvo só neste aparelho.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Resource owner: benezi-dev · Repository access: só o repo do sistema
  3. Permissões: Issues, Pull requests e Contents em Read and write (para os botões); Actions em Read-only. Metadata entra sozinha.
  4. Só com leitura o painel funciona, mas os botões vão dar erro de permissão.
